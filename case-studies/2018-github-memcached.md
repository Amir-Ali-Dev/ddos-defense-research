# GitHub 2018

- Occurrence: 2018-02-28.
- Publication: 2018-03-01.
- Primary source: [GitHub incident operator](https://github.blog/news-insights/company-news/ddos-incident-report/).
- Reviewed: 2026-10-19.

## Reported observation

GitHub reports a peak of 1.35 Tbps and 126.9 million packets/s. It records unavailability from 17:21–17:26 UTC and intermittent unavailability until 17:30 UTC, with traffic shifted to its mitigation provider. These are operator-reported event measurements, not lab benchmarks.

## Defensive interpretation

Prearrange upstream mitigation and measure recovery with both network and user-visible service signals.

These recommendations are repository analysis, not a quotation or a reproduction procedure.
