# Contributing

Contributions should improve defensive clarity, implementation quality, or
source accuracy.

## Guidelines

- Keep examples defensive and configuration-focused.
- Prefer official documentation and primary incident reports.
- Add links to sources when case studies include concrete numbers or dates.
- Avoid offensive commands, target selection, scanning workflows, or traffic
  generation steps.
- Validate JSON and SVG files before opening a pull request.
- Use clear names for diagrams, examples, and case-study files.

## Useful Contribution Ideas

- Add Kubernetes ingress rate-limiting examples.
- Add Terraform examples for defensive CDN/WAF configuration.
- Add Prometheus/Grafana dashboard examples for DDoS detection.
- Add more case studies with timeline, defensive lessons, and architecture
  takeaways.
